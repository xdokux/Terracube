# shaderpacks

Put shaderpacks here, each as the `.zip` you downloaded or as an extracted folder. They are
OptiFine/Iris packs, unchanged; nothing needs converting.

Pick one in game under **Settings -> Shaders**. A pack is extracted into `.cache/` on first
load, and its options are written to `<pack>.options.txt` next to it, where every line is
commented out until you change it. **Settings -> Shaders -> Pack options...** edits the same
file from inside the game.

Packs that need compute shaders, custom images or shader storage buffers say so when they
load and are not run.
